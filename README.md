# Dorks & Dice Surveyor

Surveyor is the shared headless map-analysis and image-processing service for Dorks & Dice tools.

> Surveyor observes map imagery and returns analysis results. Consuming tools own accepted domain state.

The repository is being initialized for Phase 13 of Hex Crawl's generic-procedure roadmap. The baseline service is intentionally small and stateless; substantive map-analysis capabilities are developed on feature branches.
